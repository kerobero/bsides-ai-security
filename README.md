# BSides Colombia Pereira 2026 — AI Security Training

Archivos del entrenamiento de seguridad de BSides Colombia Pereira 2026

**AI Security: Ataques, Defensas y Automatización en Sistemas con Inteligencia Artificial**

Autor: Gustavo Nieves Arreaza

> Nota: Se comparten los documentos previa autorización del autor del entrenamiento.

---

## Requerimientos

- Conocimientos básicos de AppSec o ciberseguridad ofensiva/defensiva
- Familiaridad con APIs REST, JSON, HTTP
- **Ideal (no obligatorio):** experiencia básica en Python o CLI
- Laptop personal con Docker, Git y Ollama instalados
- Tener descargado el modelo `gemma3`

---

## Temario

| # | Tema | Descripción |
|---|---|---|
| 1 | **Introducción a AI Security y amenazas emergentes** | Panorama de riesgos en sistemas con IA |

| 8 | **Laboratorio final: ataque/defensa sobre arquitectura de IA simulada** | Ejercicio práctico de red team / blue team |
